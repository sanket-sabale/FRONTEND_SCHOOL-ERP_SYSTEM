\chapter{Responsiveness and Accessibility}
\section{Responsive Implementation}
The app uses mobile-first Tailwind and CSS utilities. Desktop navigation uses a sidebar from large breakpoints. Mobile uses a topbar and drawer. Data-heavy screens use responsive cards, table wrappers, and stacked forms.

\section{Actual Utilities}
Important utilities include \code{erp-container}, \code{responsive-panel}, \code{responsive-table-wrap}, \code{responsive-action-row}, \code{responsive-text}, and mobile rules below 480px.

\section{Accessibility Practices}
Implemented practices include semantic buttons, native form controls, labels through \code{Field}, focus-visible outlines, dialog roles in navigation/search surfaces, reduced-motion handling for animations, and status text in badges.

\section{Recommended Improvements}
Some controls use 36px height rather than ideal 44px touch targets. More systematic automated accessibility testing is future work.
