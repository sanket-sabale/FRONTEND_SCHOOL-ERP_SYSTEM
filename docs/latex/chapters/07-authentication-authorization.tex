\chapter{Authentication and Authorization}
\section{Authentication}
The current project has login/session routes and a mock current user. A production authentication provider, JWT lifecycle, refresh token storage, MFA, and password reset implementation are not present in the inspected source.

\section{Roles}
Actual roles are \code{principal}, \code{teacher}, \code{accountant}, \code{hr}, and \code{system-admin}.

\section{Authorization}
Authorization is implemented through \code{rolePermissions} and \code{hasPermission}. Route files and server actions use these checks to redirect or reject operations.

\section{Limitations}
\begin{warningbox}
The current RBAC is code-configured and mock-session based. It is suitable for development but not a complete production identity and access management implementation.
\end{warningbox}
