\chapter{Introduction}
\section{Purpose}
This document describes the current School ERP SaaS application implemented in \RepositoryPath. It is not a theoretical ERP design. It records what the codebase currently contains, what is mock-only, what is placeholder navigation, and what remains future scope.

\section{Target Product}
The application targets schools in India and supports operational workflows for principals, teachers, HR staff, accountants, administrators, students, and guardians. Current implementation is frontend-heavy and mock-backed.

\section{Current Maturity}
\begin{statusbox}
The application is a development-stage modular Next.js ERP shell with many implemented UI/domain modules and deterministic mock services. It is not yet a production database-backed SaaS platform.
\end{statusbox}
