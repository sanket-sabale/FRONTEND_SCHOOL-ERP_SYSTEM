\chapter{Error, Loading, and Empty States}
\section{Route State Files}
Many route directories include \code{loading.tsx} and \code{error.tsx}. The route catalog appendix marks where these are present.

\section{Common Patterns}
Implemented UI state patterns include skeleton loading, \code{EmptyState}, not-found/unavailable panels, invalid ID handling, unauthorized redirect to \code{/unauthorized}, and server action success/error messages.

\section{Gaps}
Not every dynamic route has local loading/error files; some use parent-level or component-level unavailable states.
