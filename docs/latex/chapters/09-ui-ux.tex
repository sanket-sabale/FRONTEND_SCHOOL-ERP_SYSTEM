\section{Shared UI}
Reusable primitives include \code{Button}, \code{Badge}, \code{Card}, \code{LinkButton}, \code{PageHeader}, \code{SectionHeader}, \code{EmptyState}, \code{Field}, and \code{Select}.

\section{Design Character}
The actual design is professional, minimal, data-oriented, light/dark capable, and based on cards, tables, section headers, badges, and responsive action rows.
