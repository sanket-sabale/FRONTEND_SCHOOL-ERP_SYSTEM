\chapter{Communication Center}
\section{Status}
\implemented{} as a route and feature module.

\section{Route}
The Communication Center is available at \code{/communication}.

\section{Implemented Concepts}
The source includes conversation view, communication center shell, message composer, rich text renderer, attachment message rendering, skeleton states, and a communication API service.

\section{Permissions}
Communication permissions are \code{communication.view}, \code{communication.send}, \code{communication.broadcast}, \code{communication.notice.create}, and \code{communication.manage}.

\section{Limitations}
External SMS, WhatsApp, email provider delivery, and push notifications are not implemented in the inspected source.
