\chapter{Promotions}
\section{Status}
\implemented{} under Academic routes and student-promotion feature modules.

\section{Routes}
Promotion routes include \code{/academics/promotions}, \code{/academics/promotions/[promotionId]}, \code{/academics/promotions/bulk-preview}, \code{/academics/promotions/audit}, and \code{/academics/promotions/audit/[promotionId]}.

\section{Safeguards}
Promotion candidates, bulk preview/preparation, audit records, transition evidence, and correlation concepts are implemented. Bulk preview/preparation is not the same as bulk application.

\section{Source Modules}
Promotion types, schemas, services, mock data, rules, actions, management, detail, batch workspace, and audit components exist under \code{src/features/student-promotions}.
