\chapter{Introduction}
\section{Background}
\ProjectName{} is a school operations platform for Indian schools. The project is currently implemented as a Next.js, React, TypeScript, App Router application with a tenant-scoped mock/in-memory service architecture. It is designed to evolve into a practical modular monolith suitable for a solo developer or small engineering team.

\section{Problem Statement}
Schools need a single operational system for students, guardians, attendance, academic structure, communication, staff records, and HR workflows. The system must handle role-specific access, multiple campuses or schools, and strict tenant isolation without becoming over-engineered.

\section{Vision and Objectives}
The product vision is a professional ERP workspace for school administration. Core objectives are tenant-safe operations, dense data-heavy UI, predictable service boundaries, maintainable feature modules, and gradual migration from mock services to production persistence.

\section{Target Users}
Primary users include Platform Super Admin, School Admin, Principal, Teacher, Accountant, HR, Parent, and Student. The current source primarily models principal, teacher, accountant, HR, and system-admin roles.

\section{Documentation Purpose}
This document supports architecture review, onboarding, technical handover, project planning, future AI coding-agent context, and academic/project submission.
