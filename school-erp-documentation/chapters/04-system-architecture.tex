\chapter{System Architecture}
\section{Current Architecture}
The current system is a Next.js application with App Router pages, shared UI components, server actions, tenant context helpers, domain services, schemas, and mock/in-memory datasets.

\section{Intended Production Direction}
The requested architecture direction is:
\begin{center}
Next.js $\rightarrow$ REST API $\rightarrow$ NestJS $\rightarrow$ Services $\rightarrow$ Repository/Data Access $\rightarrow$ Prisma $\rightarrow$ PostgreSQL
\end{center}
This backend stack is not currently present in the repository and is therefore documented as \statusplanned.

\section{Dependency Direction}
UI should call actions or API boundaries. Actions/services enforce permissions, validation, and tenant scope. Components must not import mock repositories directly.
