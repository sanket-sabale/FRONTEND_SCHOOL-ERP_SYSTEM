\chapter{Communication Center}
\section{Status}
\statusimplemented

\section{Implemented Surface}
The Communication Center is routed at \texttt{/communication}. Source files include conversation view, rich text rendering, attachment message rendering, composer, skeleton states, and API boundary.

\section{Capabilities}
Implemented concepts include Inbox, Chats, Groups, Channels, Broadcasts, Notices, rich text, attachments, drafts, and permission-aware send behavior.

\section{Permissions}
Communication permissions include \texttt{communication.view}, \texttt{communication.send}, \texttt{communication.broadcast}, \texttt{communication.notice.create}, and \texttt{communication.manage}.

\section{Limitations}
External delivery integrations such as SMS, WhatsApp, email providers, and push notification services are not currently specified as implemented.
