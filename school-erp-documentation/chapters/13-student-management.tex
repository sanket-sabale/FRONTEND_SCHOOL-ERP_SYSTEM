\chapter{Student Management}
\section{Status}
\statusimplemented

\section{Architecture}
Student Management is implemented under \texttt{src/features/students} with types, schemas, services, hooks, actions, and components. Routes include \texttt{/students}, \texttt{/students/new}, \texttt{/students/[studentId]}, \texttt{/students/[studentId]/edit}, and placement-related routes.

\input{diagrams/student-management-map}

\section{Capabilities}
Implemented capabilities include student directory, create/edit forms, profile, lifecycle controls, document panel, status badges, tenant-scoped service boundaries, and placement integration.

\section{Permissions}
Student reads use \texttt{student.view}. Create and update flows use \texttt{student.create} and \texttt{student.update}. Additional management permissions exist in the RBAC matrix.

\section{Limitations}
Production database persistence, advanced admission automation, and external document storage are not currently implemented.
