\chapter{Security}
\section{Implemented Security Controls}
\begin{itemize}
\item RBAC permission matrix in \texttt{src/config/navigation.ts}.
\item \texttt{hasPermission} helper used by routes and actions.
\item Trusted mock tenant context in \texttt{src/lib/tenant-context.ts}.
\item Server actions for sensitive mutations.
\item Zod schemas and service rules for validation.
\end{itemize}

\section{Sensitive Data}
Staff documents, HR records, accounts, attendance, and student records are sensitive. File/document services use metadata and mock storage abstractions; real public file URLs are not implemented.

\section{Attack Considerations}
The production system should guard against IDOR, cross-tenant access, unsafe file paths, direct object access, input tampering, broken authorization, and leaking internal errors.

\begin{securitybox}
Knowing a URL such as \texttt{/staff/<id>} must not be enough to access another tenant's staff record. Services must always check tenant scope.
\end{securitybox}
