\chapter{Testing and Quality}
\section{Currently Configured}
The project has scripts for development, production build, and linting. TypeScript compilation can be run directly through \texttt{tsc --noEmit}. ESLint and Next.js build are used repeatedly during implementation phases.

\section{Quality Commands}
\begin{lstlisting}[language=bash]
.\node_modules\.bin\tsc.cmd --noEmit
.\node_modules\.bin\eslint.cmd src --ext .ts,.tsx
.\node_modules\.bin\next.cmd build
git diff --check
\end{lstlisting}

\section{Browser QA}
Recent implementation phases used route smoke tests and responsive checks at mobile, tablet, and desktop sizes. This is manual/browser-assisted QA, not a committed automated E2E suite.

\section{Recommended Future Testing}
Unit tests, integration tests, Playwright E2E tests, security tests, tenancy isolation tests, and accessibility checks should be added before production launch.
