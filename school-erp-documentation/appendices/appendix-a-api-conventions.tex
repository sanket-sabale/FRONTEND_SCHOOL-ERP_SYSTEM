\section{Current Pattern}
Current route and action code follows:
\begin{center}
UI / Route $\rightarrow$ Server Action or API Boundary $\rightarrow$ Service $\rightarrow$ Rules / Mock Data
\end{center}

\section{Error Shape}
The current \texttt{ApiError} includes a code, message, and optional request identifier. User-facing screens should translate technical failures into friendly unavailable states.
